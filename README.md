# Scard AI Demo (Smart Cards AI)

Personal AI Assistant and Business Automation Platform.

## 📌 Project Overview
Scard AI is a comprehensive AI-powered assistant and business automation platform engineered to streamline daily tasks, intelligent reminders, email automation, document analysis, and conversational workflows.

### Components
- **`smart_cards_app/`**: Flutter mobile application (Android & iOS) implementing dynamic cards, dashboard, voice interactions, and state management (Riverpod).
- **`index.html` & `sample-01.html`**: Interactive web prototypes and dashboards.
- **`BRD.md`**: Detailed Business Requirements Document outlining full system architecture, personas, workflows, and specifications.
- **`ANALYSIS.md` & `FLUTTER_DEVELOPMENT_PLAN.md`**: Architectural breakdown and Flutter step-by-step development roadmap.

## 🚀 Getting Started

### Flutter App
1. Navigate to the app directory:
   ```bash
   cd smart_cards_app
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```

### Web Prototypes
Open `index.html` or `sample-01.html` directly in any modern web browser or serve via a local web server (e.g., Apache/XAMPP).
